# 飞书提醒助手 · 0.2.2

个人安卓设备上的定时任务助手。到点提醒并打开飞书页面，可用于日报、会议、上下班打卡等。照片由本人现场拍摄、提交。

## 使用

1. 在 [Releases](https://github.com/fangqqqqqq/daka/releases) 下载 APK。本次提供的 0.2.2 安装包沿用旧版签名，可覆盖安装，保留已有设置与任务状态。
2. 概览页显示下一次提醒、今天的任务、设备时间与时区；打开“提醒总开关”。
3. 任务页点击“新增任务”，设置名称、时间和重复星期，然后启用这项任务。新任务先保持停用，方便完成配置。
4. 每项任务可设置独立飞书入口；留空时使用设置页的默认入口。也可独立选择仅提醒、自动打开页面或考勤辅助。
5. 修改自动保存。文字停止输入 0.7 秒后生效，离开页面立即保存；格式未补全时保留草稿及上次有效设置。
6. 设置页提供默认入口、默认执行方式、铃声开关、振动、响铃时长（15／30／60／90 秒）、稍后提醒间隔（1／2／5／10／15 分钟）、休假／补班和权限入口。
7. 需要检查新入口时，可在任务页使用“测试此任务”，十秒后提醒并打开页面，测试不会点击打卡。首页已移除快速验证模块。
8. 在任务编辑页删除任务，系统同步取消它的后续提醒。停用一项任务不影响其他任务。

原来的上班／下班现在也是可编辑、可删除的任务。任务可以同名；内部使用独立标识，各自调度及记录完成状态。界面与本机偏好中已移除运行记录。

## 规则与权限

- 时间使用设备当前时区。已过的时间安排到下一次，不补响；首页明确显示设备时间与时区。
- 日期规则优先休假，再补班，再重复星期。每项任务可选择是否遵循休假／补班。
- 已完成或跳过后修改时间，会形成新的提醒安排，状态自动变回“待提醒”，可以在当天再次触发。新时间若已经过去则安排到下一次。仅修改名称或入口、重复保存同一时间不会重新触发；改回曾用过的时间也作为一次新安排。旧闹钟、旧稍后提醒与旧通知不能影响新安排。
- 同时到点的任务进入提醒队列，当前提醒完成、跳过或结束后处理下一项；提醒内容与入口独立。
- 需要通知与精准闹钟。锁屏全屏、悬浮提醒、自启动／后台运行和电池优化须按设备设置。
- 设置新增“开启息屏后台保护”、提醒通道与锁屏通知、系统闹钟音量。后台保护需用户在系统提示中授权；一加 13T／Ace 还需在应用信息／电池管理允许后台活动与自启动，系统版本之间名称可能不同。厂商开关无法由统一 Android API 完整检测。
- 服务启动前保持短时唤醒，提醒期间保持有界唤醒；铃声使用闹钟音频通道，系统铃声不可播放时使用备用提示音。不会擅自调高系统闹钟音量，闹钟音量为零或系统策略仍会影响声音。
- 打开飞书后保留顶部浮窗，可展开或收起；单次提醒最多保持两分钟，响铃时长只控制声音。完成、跳过、稍后提醒或超时会移除浮窗。系统权限页面及主动隐藏悬浮窗的页面可能遮蔽浮窗。
- 密码锁屏需本人解锁。系统或一加后台策略仍可能阻止后台启动。
- 普通任务只提醒／打开页面。自动点击考勤入口需明确选择上班或下班类型、考勤辅助模式并授权无障碍；只在当前任务会话识别官方飞书，不读取聊天。
- 只尝试一次考勤入口；遇到拍照、人脸、验证或页面不明确时交给用户，不代拍、不替换照片、不自动提交。
- 成功状态基于新的页面提示或人工确认，不等同于服务器 API 校验。

## 电脑模拟器

本地启动脚本用于已配置的项目专属 Android 15 AVD；新电脑需先安装 Android Studio、创建模拟器并调整脚本中的 SDK／AVD 路径。在项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\start-test-emulator.ps1"
```

脚本复用正在运行的项目设备，并等待启动后校准为 `Asia/Shanghai`。也可通过 `-TimeZone` 指定其他时区。执行策略参数仅影响这次进程。

当前测试设备使用离线“QA 飞书接收器”。联调公司日报时，先卸载它，再从 [飞书官网](https://www.feishu.cn/download) 安装安卓飞书，由本人登录。APK 可以拖到模拟器窗口安装。模拟器不代表一加厂商后台策略和真实拍照已经验证。

## 构建与检查

JDK 17，Android SDK 35，Gradle 8.7，AGP 8.6.0。原生 Java UI，无第三方运行时依赖。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -JavaHome 'JDK目录' -SdkPath 'SDK目录'
```

构建脚本运行构建、单元测试、lint，输出 APK 与 SHA-256。自动保存与任务检查使用 Android 集成测试；后台自定义任务用离线接收器验证。详见 `qa/README.md`、`docs/verification.md`。

首次构建前，在本机 `local.properties` 中设置 `sdk.dir=你的SDK路径`，或配置 `ANDROID_HOME`。本机 SDK 路径、构建缓存、模拟器、签名密钥及 APK 不提交到源码仓库，安装包放在 Releases。自行构建默认使用本机调试签名；覆盖既有安装需要使用相同签名，原签名密钥不公开。

版本变化见 [CHANGELOG.md](CHANGELOG.md)。应用运行不需要服务端，不包含账号密码；飞书入口及任务配置保存在设备本机。
